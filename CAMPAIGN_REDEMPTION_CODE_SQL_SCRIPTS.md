# Campaign Redemption Code - SQL Scripts Reference

## Overview
This document contains ready-to-use SQL scripts for managing campaign redemption codes and tracking redemptions back to campaigns.

## 1. Setup & Migration Scripts

### Create Campaign Redemption Code Support (V3 Migration)

```sql
-- ============================================================================
-- V3__add_campaign_redemption_codes.sql
-- ============================================================================

-- Add has_redemption_code flag to campaigns table
ALTER TABLE campaigns
    ADD COLUMN has_redemption_code BOOLEAN NOT NULL DEFAULT false;

-- Create index for campaigns with codes enabled
CREATE INDEX idx_campaigns_has_redemption_code ON campaigns(has_redemption_code);

-- Create composite index for campaign code lookups
CREATE INDEX idx_redemptions_campaign_status ON redemptions(campaign_id, status);

-- Create index for code expiry queries (batch cleanup jobs)
CREATE INDEX idx_redemptions_code_expires_at ON redemptions(code_expires_at);

-- ============================================================================
-- Verification
-- ============================================================================

FROM information_schema.columns 
WHERE table_name = 'campaigns' 
  AND column_name = 'has_redemption_code';

-- Verify indexes were created
SELECT indexname 
FROM pg_indexes 
WHERE tablename = 'redemptions' 
  AND indexname LIKE 'idx_redemptions_%';
```

## 2. Campaign Code Generation (at Publish Time)

### Script A: Generate Codes for Existing Campaign

```sql
-- Use this to generate codes for a campaign that was published without codes
-- WARNING: Only run once per campaign!

-- Parameters: Set these before running
SET @campaign_id = 1;
SET @restaurant_id = 1;
SET @code_ttl_hours = 24;

-- Step 1: Verify campaign exists and codes haven't been generated yet
SELECT id, name, has_redemption_code, reach, status
FROM campaigns
WHERE id = @campaign_id;
-- Expected: has_redemption_code = true, reach > 0

-- Step 2: Check existing codes for this campaign
SELECT COUNT(*) as existing_codes
FROM redemptions
WHERE campaign_id = @campaign_id;
-- Expected: 0 (no codes yet)

-- Step 3: Insert redemption codes (requires application layer to generate codes)
-- This is a TEMPLATE - actual codes must be generated by application
-- because we need to ensure uniqueness across the entire redemptions table

INSERT INTO redemptions (
    campaign_id,
    redemption_code,
    guest_phone,
    status,
    code_expires_at,
    restaurant_id,
    created_at,
    updated_at
)
VALUES 
    (@campaign_id, '514527', '+1-647-111-1111', 'GENERATED', NOW() + INTERVAL '@code_ttl_hours hours', @restaurant_id, NOW(), NOW()),
    (@campaign_id, '928301', '+1-647-222-2222', 'GENERATED', NOW() + INTERVAL '@code_ttl_hours hours', @restaurant_id, NOW(), NOW()),
    (@campaign_id, '772845', '+1-647-333-3333', 'GENERATED', NOW() + INTERVAL '@code_ttl_hours hours', @restaurant_id, NOW(), NOW());

-- Step 4: Verify codes were created
SELECT COUNT(*) as codes_created
FROM redemptions
WHERE campaign_id = @campaign_id AND status = 'GENERATED';
```

## 3. Campaign Code Validation (at POS)

### Script B: Find Valid Campaign Code

```sql
-- Use this to validate a code when guest enters it at POS
-- Returns the redemption record if valid, otherwise empty result

-- Parameters
SET @code = '514527';
SET @campaign_id = 1;

-- Query: Find valid campaign-specific code
SELECT 
    r.id,
    r.redemption_code,
    r.campaign_id,
    r.guest_phone,
    r.status,
    r.code_expires_at,
    r.restaurant_id,
    c.name as campaign_name,
    c.message as campaign_message
FROM redemptions r
LEFT JOIN campaigns c ON r.campaign_id = c.id
WHERE r.redemption_code = @code
  AND r.campaign_id = @campaign_id
  AND r.status = 'GENERATED'
  AND r.code_expires_at > CURRENT_TIMESTAMP
LIMIT 1;

-- If result exists: Code is VALID
-- If no result: Code is INVALID or EXPIRED
```

### Script C: Mark Code as Completed

```sql
-- Use this to complete a code redemption after POS validation

-- Parameters
SET @code = '514527';
SET @campaign_id = 1;

-- Update the redemption to COMPLETED
UPDATE redemptions
SET 
    status = 'COMPLETED',
    redeemed_at = CURRENT_TIMESTAMP,
    updated_at = CURRENT_TIMESTAMP
WHERE redemption_code = @code
  AND campaign_id = @campaign_id
  AND status = 'GENERATED'
  AND code_expires_at > CURRENT_TIMESTAMP;

-- Verify update
SELECT id, status, redeemed_at 
FROM redemptions 
WHERE redemption_code = @code AND campaign_id = @campaign_id;
-- Expected: status = 'COMPLETED', redeemed_at = current timestamp
```

## 4. Campaign Performance Tracking

### Script D: Campaign Redemption Summary

```sql
-- Get complete redemption stats for a campaign

SET @campaign_id = 1;

SELECT 
    c.id as campaign_id,
    c.name as campaign_name,
    c.message,
    c.audience,
    c.status,
    c.reach,
    c.sent_count,
    c.has_redemption_code,
    c.created_at,
    COUNT(CASE WHEN r.status = 'GENERATED' THEN 1 END) as codes_generated,
    COUNT(CASE WHEN r.status = 'COMPLETED' THEN 1 END) as codes_redeemed,
    COUNT(CASE WHEN r.status = 'GENERATED' AND r.code_expires_at < CURRENT_TIMESTAMP THEN 1 END) as codes_expired,
    COUNT(CASE WHEN r.status = 'CANCELLED' THEN 1 END) as codes_cancelled,
    ROUND(
        100.0 * COUNT(CASE WHEN r.status = 'COMPLETED' THEN 1 END) / 
        NULLIF(COUNT(CASE WHEN r.status = 'GENERATED' THEN 1 END), 0),
        2
    ) as redemption_rate_pct
FROM campaigns c
LEFT JOIN redemptions r ON c.id = r.campaign_id
WHERE c.id = @campaign_id
GROUP BY c.id, c.name, c.message, c.audience, c.status, c.reach, c.sent_count, c.has_redemption_code, c.created_at;
```

### Script E: Detailed Campaign Redemption Breakdown

```sql
-- Get line-by-line redemption details for a campaign

SET @campaign_id = 1;

SELECT 
    r.id as redemption_id,
    r.redemption_code,
    r.guest_phone,
    r.status,
    r.code_expires_at,
    CASE 
        WHEN r.code_expires_at < CURRENT_TIMESTAMP THEN 'EXPIRED'
        WHEN r.status = 'COMPLETED' THEN 'REDEEMED'
        ELSE 'PENDING'
    END as code_status,
    r.created_at as code_generated_at,
    r.redeemed_at,
    EXTRACT(EPOCH FROM (r.redeemed_at - r.created_at)) / 3600 as hours_to_redeem,
    c.name as campaign_name
FROM redemptions r
LEFT JOIN campaigns c ON r.campaign_id = c.id
WHERE r.campaign_id = @campaign_id
ORDER BY r.created_at DESC;
```

## 5. Code Cleanup & Maintenance

### Script F: Expire Codes Older Than TTL

```sql
-- Mark codes as expired if their expiry time has passed
-- Run this periodically (e.g., daily cleanup job)

SET @campaign_id = 1;

UPDATE redemptions
SET 
    status = 'EXPIRED',
    updated_at = CURRENT_TIMESTAMP
WHERE campaign_id = @campaign_id
  AND status = 'GENERATED'
  AND code_expires_at < CURRENT_TIMESTAMP;

-- Report how many were expired
SELECT ROW_COUNT() as codes_expired;
```

### Script G: Bulk Expire Codes for Campaign

```sql
-- Manually expire all unredeemed codes for a campaign
-- Use when campaign ends early or is cancelled

SET @campaign_id = 1;
SET @reason = 'Campaign ended early';

UPDATE redemptions
SET 
    status = 'CANCELLED',
    updated_at = CURRENT_TIMESTAMP
WHERE campaign_id = @campaign_id
  AND status = 'GENERATED'
  AND code_expires_at > CURRENT_TIMESTAMP;

-- Verify
SELECT COUNT(*) as codes_cancelled
FROM redemptions
WHERE campaign_id = @campaign_id AND status = 'CANCELLED';
```

## 6. Campaign Code Comparison Queries

### Script H: Compare Multiple Campaigns

```sql
-- Compare redemption performance across multiple campaigns

SELECT 
    c.id as campaign_id,
    c.name,
    c.created_at,
    c.reach,
    c.has_redemption_code,
    COUNT(r.id) as total_codes,
    COUNT(CASE WHEN r.status = 'COMPLETED' THEN 1 END) as redeemed,
    COUNT(CASE WHEN r.status = 'GENERATED' THEN 1 END) as unredeemed,
    COUNT(CASE WHEN r.status = 'EXPIRED' THEN 1 END) as expired,
    ROUND(
        100.0 * COUNT(CASE WHEN r.status = 'COMPLETED' THEN 1 END) / 
        NULLIF(COUNT(r.id), 0),
        2
    ) as redemption_rate_pct
FROM campaigns c
LEFT JOIN redemptions r ON c.id = r.campaign_id
WHERE c.has_redemption_code = true
GROUP BY c.id, c.name, c.created_at, c.reach, c.has_redemption_code
ORDER BY c.created_at DESC;
```

### Script I: Top Performing Campaigns

```sql
-- Find campaigns with highest redemption rates

SELECT 
    c.id,
    c.name,
    c.reach,
    COUNT(CASE WHEN r.status = 'COMPLETED' THEN 1 END) as redeemed,
    ROUND(
        100.0 * COUNT(CASE WHEN r.status = 'COMPLETED' THEN 1 END) / 
        NULLIF(COUNT(CASE WHEN r.status = 'GENERATED' THEN 1 END), 0),
        2
    ) as redemption_rate_pct
FROM campaigns c
LEFT JOIN redemptions r ON c.id = r.campaign_id
WHERE c.has_redemption_code = true
GROUP BY c.id, c.name, c.reach
HAVING COUNT(CASE WHEN r.status = 'GENERATED' THEN 1 END) > 0
ORDER BY redemption_rate_pct DESC
LIMIT 10;
```

## 7. Data Integrity Checks

### Script J: Verify Campaign-Redemption Mapping

```sql
-- Check for orphaned redemptions or missing campaigns

-- Find redemptions with no corresponding campaign
SELECT COUNT(*) as orphaned_redemptions
FROM redemptions r
WHERE r.campaign_id IS NOT NULL
  AND r.campaign_id NOT IN (SELECT id FROM campaigns);
-- Expected: 0

-- Find campaigns with no redemptions (even though they should have)
SELECT c.id, c.name, c.has_redemption_code
FROM campaigns c
WHERE c.has_redemption_code = true
  AND c.status = 'ACTIVE'
  AND c.id NOT IN (SELECT DISTINCT campaign_id FROM redemptions WHERE campaign_id IS NOT NULL);
-- These campaigns published with codes but no redemption records exist (potential issue)
```

### Script K: Validate Code Uniqueness

```sql
-- Ensure all redemption codes are unique (should never have duplicates)

SELECT redemption_code, COUNT(*) as count
FROM redemptions
WHERE redemption_code IS NOT NULL
GROUP BY redemption_code
HAVING COUNT(*) > 1;
-- Expected: 0 rows (empty result means all codes are unique)
```

### Script L: Check Code Expiry Consistency

```sql
-- Verify codes marked EXPIRED actually have expired
-- Find codes with EXPIRED status but future expiry times (data inconsistency)

SELECT id, redemption_code, status, code_expires_at
FROM redemptions
WHERE status = 'EXPIRED'
  AND code_expires_at > CURRENT_TIMESTAMP;
-- Expected: 0 rows (no inconsistencies)
```

## 8. Analytics Queries

### Script M: Campaign ROI Analysis

```sql
-- Estimate ROI by tracking code redemptions back to campaigns

SET @restaurant_id = 1;
SET @discount_per_code = 5.00;  -- Assume $5 average discount per code

SELECT 
    c.id as campaign_id,
    c.name,
    c.reach as potential_customers,
    COUNT(CASE WHEN r.status = 'COMPLETED' THEN 1 END) as customers_redeemed,
    COUNT(CASE WHEN r.status = 'COMPLETED' THEN 1 END) * @discount_per_code as estimated_cost,
    c.sent_count as sms_sent,
    ROUND(
        100.0 * COUNT(CASE WHEN r.status = 'COMPLETED' THEN 1 END) / 
        NULLIF(c.reach, 0),
        2
    ) as conversion_rate_pct
FROM campaigns c
LEFT JOIN redemptions r ON c.id = r.campaign_id
WHERE c.restaurant_id = @restaurant_id AND c.has_redemption_code = true
GROUP BY c.id, c.name, c.reach, c.sent_count, c.restaurant_id
ORDER BY conversion_rate_pct DESC;
```

### Script N: Hourly/Daily Redemption Trend

```sql
-- Track redemptions over time to identify peak periods

SET @campaign_id = 1;

SELECT 
    DATE(r.redeemed_at) as redemption_date,
    EXTRACT(HOUR FROM r.redeemed_at) as hour_of_day,
    COUNT(*) as redemptions_count,
    COUNT(*) * 100.0 / SUM(COUNT(*)) OVER (PARTITION BY DATE(r.redeemed_at)) as pct_of_day
FROM redemptions r
WHERE r.campaign_id = @campaign_id AND r.status = 'COMPLETED'
GROUP BY DATE(r.redeemed_at), EXTRACT(HOUR FROM r.redeemed_at)
ORDER BY redemption_date DESC, hour_of_day ASC;
```

  AND code_expires_at < CURRENT_TIMESTAMP
